Kirk Vander Ploeg — professional portfolio

Buildless HTML/CSS site intended for the existing Kirk-V.github.io GitHub Pages repository.
The main page is index.html; its styles are assets/css/portfolio.css.
No package dependencies, build step, formatter, linter, or test runner are configured.

Local preview (from this directory):
    python -m http.server 8000
Then open http://localhost:8000 in a browser.

The older HTML5 UP template and its supporting assets remain in index_old.html.
Public email, LinkedIn, and GitHub destinations are defined directly in index.html.
No resume file or URL is currently available.
